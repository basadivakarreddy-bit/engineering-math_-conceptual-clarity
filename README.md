# 📐 Engineering Mathematics: Conceptual Clarity

A hands-on learning lab for engineers who want to understand the math behind real systems, not just memorize formulas.

This app combines interactive visual tools, guided proof explorations, concept mapping, and adaptive quiz practice — all wrapped inside a polished learning experience.

---

## 🚀 Jump In

1. Open the app and **log in** using the built-in authentication screen.
2. Use the top navigation tabs to switch between:
   - **Foundations** — learning modules and animated concept summaries
   - **Interactive** — 3D graphs, vector visualizers, and transformation demos
   - **Concept Map** — a visual network of engineering math ideas
   - **Step-by-Step** — expandable proof explanations and reasoning paths
   - **Quizzes** — knowledge checks with instant feedback
3. Toggle **dark/light mode** to match your working environment.

---

## ✨ What You Can Explore

### Foundations
- Start with the core building blocks of engineering math.
- Review animated math concepts that help you connect algebra, calculus, and vectors to real problems.
- Ideal for students who want a quick refresher before diving deeper.

### Interactive
- Explore **3D surface graphs** and **real-time visualizations**.
- Adjust parameters and watch how equations change shape and behavior.
- See how **linear transformations**, **field flows**, and physical boundary concepts behave visually.

### Concept Map
- Discover how major engineering math topics relate to one another.
- Use this section to build a mental model of how proofs, algebra, calculus, and vector fields fit together.

### Step-by-Step Proofs
- Read through proof logic in manageable sections.
- The accordion format guides learners through each reasoning step.
- Great for building confidence on topics like mathematical foundations and derivations.

### Quizzes
- Test your understanding with quick assessment challenges.
- Get instant validation and see which concepts need review.

---

## 🧪 How to Use the App

- Click each tab in the top navbar to switch the learning mode.
- Interact with graphs and models in the **Interactive** section.
- Open proof sections in **Step-by-Step** to follow the argument one block at a time.
- Use **Sign Out** to return to the login screen and restart the session.

---

## 🛠️ Stack & Setup

- **React 19** + **TypeScript**
- **Vite** for fast local development
- **@google/genai** for AI-driven concept support
- Custom interactive visuals built into the app UI

### Local setup
```bash
npm install
npm run dev
```

### Build for production
```bash
npm run build
```

## 💡 Notes

- The app includes a polished UI with **dark/light mode** support.
- Navigation is designed for fast exploration and self-guided learning.
